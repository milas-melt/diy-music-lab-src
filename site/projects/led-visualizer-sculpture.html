LED Visualizer Sculpture

← Back

Concept: Build a sound-reactive light sculpture with addressable LEDs (WS2812/NeoPixel). Audio is analyzed in real time on the Teensy (mic/line-in), then mapped to animations (bars, waves, bursts) that pulse with your music.

Finish line: A reliable, bright visual piece you can leave running on a desk/shelf. Modular code so you can add new visual “modes”. Safe power design, tidy wiring, and an enclosure/frame that looks artsy.

Bill of Materials (BOM)

  • Brains
    • 1× Teensy 4.1
    • (Recommended) 1× Teensy Audio Shield Rev D/D2 (SGTL5000) for clean line-in / headphone monitoring
  • LEDs & Power
    • WS2812B (a strip, ring, or matrix). Pick your count N (from 60 up to 300+)
    • 5 V DC power supply sized for LEDs: Current_max = N × 60 mA (worst-case white). Practical rule: plan ~30 mA/LED. Example: 150 LEDs → 4.5 A–9 A PSU
    • 1× 1000 µF electrolytic capacitor (≥6.3 V) across 5 V & GND near the strip
    • 1× 330 Ω resistor in series with the LED data line
    • (Recommended) 1× 74HCT245 or 74HCT14 level shifter (3.3 V → 5 V data)
    • Decent gauge wire for power injection (18–20 AWG), and JST or screw terminals
  • Audio In (choose one)
    • Line-in via Audio Shield from your phone/PC/mixer (3.5 mm AUX)
    • Electret mic + preamp breakout (if you want the sculpture to listen to the room)
  • Build & Enclosure
    • Acrylic sheet(s) (clear/frosted) or wire/wood frame for the sculpture
    • Standoffs, zip ties, heat-shrink, perfboard for the level shifter
    • Soldering iron, solder, side cutters, wire stripper
  • Software (Arduino + libs)
    • Arduino IDE 2.x + Teensy support (Boards Manager → “Teensy”)
    • Either FastLED or Adafruit_NeoPixel (examples below use FastLED)

Roadmap (do in order)

  1. Stage A — LED Bring-Up: Power + test pattern (no audio). Verify wiring, brightness, and fps.
  2. Stage B — Audio Level Reactive: Simple VU meter / pulse using input amplitude (no FFT yet).
  3. Stage C — FFT Bands: Split audio into frequency bands and drive multiple zones/animations.
  4. Stage D — Sculpture: Build your frame, diffuse the LEDs, tidy the harness, safe power.

Power & Safety (read before wiring)

  • Size PSU for your LED count (N). Start with 30 mA/LED for planning. Example: 120 LEDs → ~3.6 A supply (use 5 A if you can).
  • Always connect grounds: LED 5 V– PSU+, LED GND– PSU−, Teensy GND– PSU− (common ground).
  • Put a 1000 µF cap across 5 V and GND at the strip start. Data line: Teensy pin → 330 Ω → LED DIN.
  • Use a 74HCT-series level shifter. Teensy 4.1 is 3.3 V; many WS2812s work with 3.3 V data at 5 V power, but a shifter is more robust.
  • Power injection every 50–100 LEDs to avoid voltage drop. Run extra 5 V/GND feeds to the middle/end of long strips.
  • Never hot-plug the data line before grounds are connected.

            ├─────────────── LED +5V (mid injection)

PSU GND ────┬─────────────── LED GND (start)

            └─────────────── LED GND (end injection)

Wiring (Audio)

Option 1 — Audio Shield (recommended): Plug music into the shield’s Line In. Teensy reads audio via I²S, clean and simple.

Option 2 — Mic Preamp: Connect an electret mic breakout’s analog output to an ADC pin (e.g., A2) with proper bias/conditioning. Simpler to wire but noisier; FFT still works for a flashy sculpture.

Stage A — LED Bring-Up (no audio)

Goal: strip lights up with a moving test pattern. Confirm power, data direction, and frame rate.

// ---------- FastLED basic test (Teensy 4.1) ----------
#include <FastLED.h>

#define LED_PIN   7        // pick a Teensy pin, then level-shift it
#define NUM_LEDS  120      // set to your actual count
#define LED_TYPE  WS2812B
#define COLOR_ORDER GRB

CRGB leds[NUM_LEDS];

void setup() {
  FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS).setCorrection(TypicalLEDStrip);
  FastLED.setBrightness(128); // 0..255
}

void loop() {
  // simple rainbow chase
  static uint8_t hue = 0;
  for (int i=0; i<NUM_LEDS; ++i) leds[i] = CHSV(hue + i*3, 255, 255);
  FastLED.show();
  hue++;
  delay(16); // ~60 fps
}

Pass: Bright, smooth animation. If flicker/garbage: check arrow direction on strip, level shifter orientation, common ground, and the 330 Ω resistor.

Stage B — Audio Level Reactive (no FFT)

Goal: LEDs pulse with loudness (VU style). Works with Audio Shield line-in or a mic sensor. This verifies your input path before FFT.

Variant 1: Audio Shield (line-in, recommended) 
// Teensy 4.1 + Audio Shield — LED reacts to input amplitude
#include <Audio.h>
#include <Wire.h>
#include <SPI.h>
#include <FastLED.h>

#define LED_PIN 7
#define NUM_LEDS 120
CRGB leds[NUM_LEDS];

// Audio graph
AudioInputI2S       in1;      // from SGTL5000 line-in
AudioAnalyzePeak    peakL;
AudioAnalyzePeak    peakR;
AudioConnection     pc1(in1, 0, peakL, 0);
AudioConnection     pc2(in1, 1, peakR, 0);
AudioControlSGTL5000 sgtl5000_1;

void setup() {
  // LEDs
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(180);

  // Audio
  AudioMemory(20);
  sgtl5000_1.enable();
  sgtl5000_1.inputSelect(AUDIO_INPUT_LINEIN); // or MIC if wired
  sgtl5000_1.lineInLevel(5);  // adjust to taste

  // baseline clear
  fill_solid(leds, NUM_LEDS, CRGB::Black);
  FastLED.show();
}

void loop() {
  if (peakL.available() && peakR.available()) {
    float a = (peakL.read() + peakR.read()) * 0.5f; // 0..1-ish
    a = constrain(a, 0.0f, 1.0f);

    int n = (int)(a * NUM_LEDS);
    for (int i=0;i<NUM_LEDS;i++) leds[i] = (i<n) ? CRGB(0, 0, 255) : CRGB::Black; // blue VU
    FastLED.show();
  }
}
Variant 2: Mic breakout on analog pin (quick hack) 
// Teensy 4.1 — analog mic VU (basic AC-coupled amplitude)
#include <FastLED.h>
#define LED_PIN 7
#define NUM_LEDS 120
CRGB leds[NUM_LEDS];

const int MIC_PIN = A2; // your mic analog output

// simple DC removal and peak detection
float dc = 0, alpha = 0.995f, peak = 0;

void setup(){
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(180);
}

void loop(){
  int raw = analogRead(MIC_PIN);        // 0..1023
  dc = alpha*dc + (1-alpha)*raw;        // running DC estimate
  float v = fabs(raw - dc);             // AC magnitude
  peak = max(peak*0.9f, v);             // decay peak

  float a = constrain(peak/200.0f, 0.0f, 1.0f); // normalize to taste
  int n = (int)(a * NUM_LEDS);

  for (int i=0;i<NUM_LEDS;i++) leds[i] = (i<n) ? CHSV(160 + i, 255, 255) : CRGB::Black;
  FastLED.show();
  delay(16);
}

Pass: Strip grows/shrinks with volume. If stuck low, increase line-in level (shield) or adjust the normalization.

Stage C — FFT Bands → Animations

Goal: split audio into frequency buckets and drive zones/colors accordingly. We’ll use the Teensy Audio Library’s 256-point FFT (covers 0–~22 kHz @ 44.1 kHz sampling). We group bins into 8 bands and assign each band to a segment of the strip.

// Teensy 4.1 + Audio Shield — 8-band FFT Visualizer (WS2812)
// Map each band to a segment with brightness based on energy.
#include <Audio.h>
#include <Wire.h>
#include <SPI.h>
#include <FastLED.h>

#define LED_PIN   7
#define NUM_LEDS  120
#define BANDS     8
CRGB leds[NUM_LEDS];

// Audio
AudioInputI2S     in1;
AudioAnalyzeFFT256 fft;
AudioConnection   pc1(in1, 0, fft, 0);
AudioControlSGTL5000 sgtl5000_1;

void setup() {
  // LEDs
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(200);

  // Audio
  AudioMemory(60);
  sgtl5000_1.enable();
  sgtl5000_1.inputSelect(AUDIO_INPUT_LINEIN);
  sgtl5000_1.lineInLevel(5);

  // FFT config
  fft.windowFunction(AudioWindowHanning1024); // smoother levels
}

void drawBands(const float bands[BANDS]) {
  // Split the strip into BANDS segments
  int seg = NUM_LEDS / BANDS;
  for (int b = 0; b < BANDS; ++b) {
    // normalize band value (tweak scaling)
    float v = constrain(bands[b] * 3.0f, 0.0f, 1.0f);
    int lit = (int)(v * seg);
    for (int i = 0; i < seg; ++i) {
      int idx = b*seg + i;
      if (idx >= NUM_LEDS) break;
      // color per-band (rainbow across bands)
      CHSV color = CHSV( (uint8_t)(b*32), 255, 255 );
      leds[idx] = (i < lit) ? color : CRGB::Black;
    }
  }
  FastLED.show();
}

void loop() {
  if (fft.available()) {
    // Read FFT magnitudes (0..1 roughly). Bins 1..127 are useful (0 is DC).
    // We'll group bins into 8 logarithmic-ish bands.
    // For 256-pt FFT at 44.1kHz, bin width ~172 Hz. Adjust ranges to taste.
    const int ranges[BANDS+1] = { 2, 4, 7, 12, 20, 36, 64, 96, 128 }; 
    float bands[BANDS] = {0};

    for (int b=0; b<BANDS; ++b) {
      float sum = 0;
      int count = 0;
      for (int i=ranges[b]; i<ranges[b+1]; ++i) {
        sum += fft.read(i); // magnitude 0..1
        count++;
      }
      float avg = (count>0) ? sum / count : 0;
      // gentle smoothing
      static float smooth[BANDS] = {0};
      smooth[b] = 0.7f*smooth[b] + 0.3f*avg;
      bands[b] = smooth[b];
    }

    drawBands(bands);
  }
}

Pass: Low bands respond to bass, higher bands to vocals/hi-hats, each driving its segment. Adjust ranges[], smoothing, and scaling to match your music and LED count.

Modes & Mapping Ideas

  • Bar Graph: Each band fills its segment (above).
  • Energy Wave: Map band energies to a color palette and draw a moving gradient across the whole strip.
  • Beat Burst: Detect low-band peaks → spawn expanding rings/sparks.
  • Symmetry: Mirror left/right halves from the center for a “totem” look.
  • Palette: Use HSV and rotate hue over time for slow color drift.

Build the Sculpture

  1. Design: Pick a form (spiral, helix, zig-zag, grid). Sketch zones that correspond to bands.
  2. Frame: Bend wire or cut acrylic ribs. Hot-glue/zip-tie the strip in place with arrows (data direction) consistent.
  3. Diffusion: Add frosted acrylic or parchment paper to soften LEDs into a glow.
  4. Electronics Bay: Mount Teensy+Shield+level-shifter on perfboard. Provide strain-relief for PSU and audio cables.
  5. Power Injection: Solder 5 V/GND feeds to middle/end points. Keep grounds star-connected to PSU ground.
  6. Final Tidy: Heat-shrink exposed joints; label connectors.

Testing & Verification

  • LED Only: Stage A pattern runs smoothly at desired brightness. No brown-outs (color doesn’t yellow on whites).
  • Audio Level: Speaking/clapping near mic or playing music into line-in makes strip pulse responsively.
  • FFT Bands: Bass-heavy tracks light low segments; hi-hats/vocals light higher segments.
  • Thermals: After 10–15 minutes, wiring and PSU remain cool/warm (not hot). If hot, reduce brightness or improve power injection.

Troubleshooting

  • No LEDs at all: Check PSU polarity, common ground, DIN direction, 330 Ω resistor, and level shifter orientation.
  • Glitchy/flicker: Ensure ground is solid, avoid long data lines (twist with GND), add level shifter, and keep wires short.
  • Dim end of strip: Add power injection mid/end; use thicker wire.
  • No audio movement (shield): Confirm inputSelect(AUDIO_INPUT_LINEIN), increase lineInLevel(), ensure audio is on the correct jack.
  • No FFT response: Verify AudioMemory() ≥ 60, window function set, and that fft.available() triggers (try louder input).
  • Hum/noise (mic): Use shielded cable, keep mic away from PSU wires, add small RC filter if needed.

Extensions

  • Modes menu: Add buttons or an encoder to switch between visual modes and adjust sensitivity/brightness.
  • Preset save: Store settings (brightness, palette, sensitivities) to EEPROM or SD.
  • MIDI reactive: Combine FFT with MIDI clock to sync strobe/tempo effects.
  • Matrix mapping: If using a matrix, map (x,y) with serpentine wiring and draw 2D effects.
