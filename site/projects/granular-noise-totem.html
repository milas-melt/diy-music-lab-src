Granular Noise Totem

← Back to Home

Concept: A sculptural granular synthesizer you build yourself. It starts as a quick lo-fi prototype (sound out of Teensy pins) and upgrades to pro-quality audio with the Teensy Audio Shield. You’ll control pitch/speed, grain length, freeze mode, and wet/dry mix. Optional: OLED display, reverb, presets.

What you’ll finish with: a working instrument that generates evolving textures and drones, with knobs and buttons in a neat enclosure — and a repeatable workflow you can reuse for samplers/FX/other synths.

Toolchain Setup (once)

  1. Install Arduino IDE 2.x.
  2. Install Teensy support (Boards Manager → “Teensy”).
  3. Set Tools → Board: Teensy 4.1; USB Type: Serial; leave default CPU speed.
  4. Verify File → Examples → Audio exists (Teensy Audio Library).
  5. Upload Blink to confirm flashing works (LED blinks).

Build Roadmap (do in order)

  1. Stage A: Lo-fi MVP (sound via Teensy MQS pins, no shield, no SD)
    • Wire 1–3 pots + 0–2 buttons.
    • Output to 3.5 mm jack using MQS pin(s) with series resistor(s).
    • Upload the minimal synth, then the granular MVP code.
    • Goal: Hear a tone; Freeze and Mode buttons work; grain length + mix respond.
  2. Stage B: Pro audio (stack Audio Shield)
    • Swap MQS output for I²S + SGTL5000 control.
    • Use shield’s headphone/line out; optionally add live input (mic/line).
    • Goal: Clean stereo, ready for performance/recording.
  3. Stage C (optional): OLED UI, reverb, presets, SD browsing, looper.

Wiring (Stage A: MQS output)

MQS is a quick prototype audio output available on Teensy 4.1 digital pins.

Teensy 4.1  (top view varies; check your pin labels)
---------------------------------------------------
Pots (B10k, each):
  Left leg  → 3.3V
  Right leg → GND
  Middle    → A0 (Pitch), A1 (Grain), A2 (Wet)

Buttons (momentary to GND):
  One side → GND
  Other    → Pin 2  (Freeze)
            Pin 3  (Mode)
  (Use INPUT_PULLUP in code.)

Audio out (mono, Left channel, safe for AUX/headphones):
  Pin 10 (MQS L) --[ 220Ω to 1kΩ ]--> 3.5mm TIP
  GND -------------------------------> 3.5mm SLEEVE
  (Optional stereo Right: Pin 12 --[resistor]--> 3.5mm RING)

Verification: After wiring, upload the Minimal Synth sketch below; you should hear a tone that changes with A0.

Code — Stage A.1 Minimal Synth (first sound)

Open a new sketch, paste, upload. Turn A0 knob to change pitch.

// Teensy 4.1 — Minimal synth to MQS (pins 10=L, 12=R)
// Wiring: A0 pot; MQS Left pin 10 → series resistor → AUX TIP; GND → SLEEVE.
#include <Audio.h>
#include <Wire.h>
#include <SPI.h>

AudioSynthWaveform   osc;
AudioOutputMQS       mqs;
AudioConnection      pc0(osc, 0, mqs, 0);  // L
AudioConnection      pc1(osc, 0, mqs, 1);  // R (duplicate)

void setup() {
  AudioMemory(12);
  osc.begin(WAVEFORM_SINE);     // SINE is softest on MQS
  osc.amplitude(0.30f);
}

void loop() {
  int raw = analogRead(A0);               // 0..1023
  float f = 40.0f + (raw/1023.0f)*1160.0f; // ~40..1200 Hz
  osc.frequency(f);
}

Pass criteria: You hear a steady tone; pitch glides smoothly with A0.

Code — Stage A.2 Granular MVP (no SD, no shield)

This routes an internal oscillator through the granular effect with controls:

  • A0 = base pitch + granular speed
  • A1 = grain length (10–300 ms)
  • A2 = wet/dry mix
  • Pin 2 (button) = Freeze toggle
  • Pin 3 (button) = Mode toggle (pitch-shift vs freeze)
// Teensy 4.1 — Granular Texture Box (no SD, no Audio Shield)
// Output via MQS pins 10/12; controls A0/A1/A2; buttons on 2/3 to GND.
#include <Audio.h>
#include <Wire.h>
#include <SPI.h>

AudioSynthWaveform       osc;
AudioEffectGranular      granular;
AudioMixer4              mix;
AudioOutputMQS           mqs;
AudioConnection pc0(osc, 0, granular, 0);
AudioConnection pc1(osc, 0, mix, 0);        // dry
AudioConnection pc2(granular, 0, mix, 1);   // wet
AudioConnection pc3(mix, 0, mqs, 0);        // L
AudioConnection pc4(mix, 0, mqs, 1);        // R

const int POT_PITCH  = A0;
const int POT_GRAIN  = A1;
const int POT_MIX    = A2;
const int BTN_FREEZE = 2;
const int BTN_MODE   = 3;

static int16_t granularMemory[24000]; // ~0.54s buffer

bool freezeMode=false, pitchMode=true, lastF=false, lastM=false;

void setup(){
  pinMode(BTN_FREEZE, INPUT_PULLUP);
  pinMode(BTN_MODE,   INPUT_PULLUP);

  AudioMemory(80);

  osc.begin(WAVEFORM_SAWTOOTH);     // rich source for grains
  osc.amplitude(0.35f);

  granular.begin(granularMemory, 24000);
  granular.beginPitchShift(1.0f);   // keep active

  mix.gain(0, 0.5f);  // dry
  mix.gain(1, 0.5f);  // wet
}

void loop(){
  // Read pots
  int rPitch = analogRead(POT_PITCH);
  int rGrain = analogRead(POT_GRAIN);
  int rMix   = analogRead(POT_MIX);

  // Osc pitch 40..1200 Hz
  float k = rPitch/1023.0f;
  float freq = 40.0f + k*(1200.0f-40.0f);
  osc.frequency(freq);

  // Granular speed 0.25x..4x (exponential)
  float speed = 0.25f * powf(16.0f, k);
  granular.setSpeed(speed);

  // Grain length 10..300 ms
  float grainMs = 10.0f + (rGrain/1023.0f)*290.0f;
  granular.setGrainLength(grainMs);

  // Wet/dry 0..1
  float wet = constrain(rMix/1023.0f, 0.0f, 1.0f);
  mix.gain(0, 1.0f - wet);
  mix.gain(1, wet);

  // Buttons (edge detect)
  bool fNow = (digitalRead(BTN_FREEZE)==LOW);
  bool mNow = (digitalRead(BTN_MODE)==LOW);

  if (fNow && !lastF){
    freezeMode = !freezeMode;
    granular.stop();
    if (freezeMode)     granular.beginFreeze(grainMs*0.001f);
    else if (pitchMode) granular.beginPitchShift(1.0f);
  }
  if (mNow && !lastM){
    pitchMode = !pitchMode;
    granular.stop();
    if (pitchMode)      granular.beginPitchShift(1.0f);
    else if (freezeMode)granular.beginFreeze(grainMs*0.001f);
  }
  lastF=fNow; lastM=mNow;
}

Pass criteria: Freeze button latches a texture; grain length knob changes character; wet/dry blends; Mode toggles behavior.

Upgrade — Stage B: Audio Shield (clean stereo, line/mic)

Stack the Teensy Audio Shield on your Teensy 4.1 (solder headers). Use the shield’s headphone jack or line out for clean audio. Code changes are minimal: switch output to I²S + enable the SGTL5000.

// Teensy 4.1 + Audio Shield (SGTL5000) — Granular Player (no SD needed yet)
#include <Audio.h>
#include <Wire.h>
#include <SPI.h>
#include <SD.h>

AudioSynthWaveform       osc;
AudioEffectGranular      granular;
AudioMixer4              mix;
AudioOutputI2S           i2s1;
AudioControlSGTL5000     sgtl5000_1;

AudioConnection pc0(osc, 0, granular, 0);
AudioConnection pc1(osc, 0, mix, 0);
AudioConnection pc2(granular, 0, mix, 1);
AudioConnection pc3(mix, 0, i2s1, 0);
AudioConnection pc4(mix, 0, i2s1, 1);

const int POT_PITCH  = A0;
const int POT_GRAIN  = A1;
const int POT_MIX    = A2;
const int BTN_FREEZE = 2;
const int BTN_MODE   = 3;

static int16_t granularMemory[32000]; // longer buffer (stereo out)

bool freezeMode=false, pitchMode=true, lastF=false, lastM=false;

void setup(){
  pinMode(BTN_FREEZE, INPUT_PULLUP);
  pinMode(BTN_MODE,   INPUT_PULLUP);

  AudioMemory(90);
  sgtl5000_1.enable();
  sgtl5000_1.volume(0.6);
  sgtl5000_1.lineOutLevel(13);

  osc.begin(WAVEFORM_SAWTOOTH);
  osc.amplitude(0.35f);

  granular.begin(granularMemory, 32000);
  granular.beginPitchShift(1.0f);

  mix.gain(0, 0.5f);
  mix.gain(1, 0.5f);
}

void loop(){
  int rPitch = analogRead(POT_PITCH);
  int rGrain = analogRead(POT_GRAIN);
  int rMix   = analogRead(POT_MIX);

  float k = rPitch/1023.0f;
  float freq = 40.0f + k*(1200.0f-40.0f);
  osc.frequency(freq);

  float speed = 0.25f * powf(16.0f, k);
  granular.setSpeed(speed);

  float grainMs = 10.0f + (rGrain/1023.0f)*290.0f;
  granular.setGrainLength(grainMs);

  float wet = constrain(rMix/1023.0f, 0.0f, 1.0f);
  mix.gain(0, 1.0f - wet);
  mix.gain(1, wet);

  bool fNow = (digitalRead(BTN_FREEZE)==LOW);
  bool mNow = (digitalRead(BTN_MODE)==LOW);
  if (fNow && !lastF){
    freezeMode = !freezeMode;
    granular.stop();
    if (freezeMode)     granular.beginFreeze(grainMs*0.001f);
    else if (pitchMode) granular.beginPitchShift(1.0f);
  }
  if (mNow && !lastM){
    pitchMode = !pitchMode;
    granular.stop();
    if (pitchMode)      granular.beginPitchShift(1.0f);
    else if (freezeMode)granular.beginFreeze(grainMs*0.001f);
  }
  lastF=fNow; lastM=mNow;
}

Pass criteria: Clean stereo sound via shield’s headphone jack; controls behave exactly like Stage A.

Enclosure Plan

  1. Pick a box (Hammond 1590B/T or ABS). Arrange 3 knobs on top, 2 buttons under them, 3.5 mm jack on side/front. If using OLED, put it centered above knobs.
  2. Mark & drill: pots (7–8 mm holes), buttons (~12 mm, depends), jack (6.5 mm for 3.5 mm socket), OLED window if desired.
  3. Mount hardware, then mount the Teensy (and Audio Shield) on standoffs or a small perfboard.
  4. Wire pots (3.3 V/GND/wiper), buttons to pins with GND, audio jack to shield output (or MQS resistors if still Stage A).
  5. Power via USB; optional: add a panel USB passthrough.

Troubleshooting (Read this if anything fails)

  • No sound (Stage A): Confirm Pin 10 → series resistor → AUX TIP; GND → SLEEVE. Try WAVEFORM_SINE. Lower amplitude to ~0.2. Make sure your speaker/headphones volume is low then up.
  • Buttons inverted: Buttons must go to GND with pinMode(INPUT_PULLUP). If always “Pressed”, wiring is wrong or pin mis-assigned.
  • Pots jittery: Ensure outer legs are 3.3 V and GND (not floating). Add 0.01–0.1 µF cap from wiper to GND if needed.
  • Harsh noise on MQS: Expected lo-fi. The Audio Shield fixes fidelity. Keep amplitude modest; series resistor 220 Ω–1 kΩ is required.
  • Compilation errors (missing classes): You must have Teensy Audio Library installed (Boards Manager “Teensy”). Use Arduino IDE 2.x with Teensy core.
  • Silence after a while: Check AudioMemory() (try 80–100). Ensure you didn’t short the output or wire wrong pins.

Safety & Best Practices

  • Don’t drive headphones directly from Teensy pins without the series resistor and only at low volume (MQS is not a headphone amp).
  • Do not power motors/relays from 3.3 V rail; keep analog audio ground clean.
  • Secure wires before closing the enclosure to avoid shorts.

Glossary (quick refresher)

  • Granular synthesis: Creating new textures by slicing sound into very short “grains” and rearranging/overlapping them.
  • Freeze: Hold a short slice and loop/overlap it to create a drone.
  • Pitch-shift (speed): Playing the buffer faster/slower (tape-like) to change pitch/timbre.
  • Wet/Dry: Balance between effected (wet) and original (dry) signals.
  • MQS: Teensy 4.x’s quick proto audio output on digital pins; good for testing, not hi-fi.
  • I²S: Digital audio bus used by the Audio Shield for high-quality stereo I/O.
